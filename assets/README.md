# assets フォルダについて

このフォルダは、将来アプリに画像や効果音ファイルを追加するための場所です。

第1段階MVPでは、画像・音声ファイルは一切使用していません。
効果音はすべて `js/audio.js` 内でWeb Audio APIにより生成しています。

## 将来の用途（想定）

- `assets/images/` : 魔法陣・背景・キャラクターなどの画像
- `assets/sounds/` : BGMや、より複雑な効果音ファイル

追加する際は、上記のようなサブフォルダを作成し、
各モジュール（`ui.js` や `audio.js` など）から相対パスで読み込んでください。
